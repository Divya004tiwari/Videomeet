# VideoMeet – Full-Stack Video Conferencing Platform

VideoMeet is a full-stack video conferencing platform that enables users to host and join secure online meetings with real-time audio/video communication, screen sharing, live chat, and meeting history. Built using modern web technologies, it delivers a seamless collaboration experience similar to popular video conferencing applications.

---

## 🚀 Features

- 🔐 Secure User Authentication
- 📹 Real-Time Video & Audio Calling
- 👥 One-to-One and Group Meetings
- 💬 In-Meeting Chat
- 🖥️ Screen Sharing
- 🎤 Camera & Microphone Controls
- 📝 Meeting History
- 🔗 Unique Meeting Room Generation
- 📱 Responsive User Interface
- ⚡ Low-Latency Communication using WebRTC & Socket.IO

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Divya004tiwari/ConnectMeet.git
cd ConnectMeet
```

### Install dependencies

Frontend

```bash
cd frontend
npm install
```

Backend

```bash
cd backend
npm install
```

---

## ▶️ Run the application

### Backend

```bash
npm start
```

### Frontend

```bash
npm start
```

The application will be available at

```
http://localhost:3000
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```
